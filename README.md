# Programming Labs – Java 2026

A collection of Java programming laboratory projects completed as part of my Computer Science coursework.

## Projects

### Lab 1 – SmartFleet
A Java application demonstrating object-oriented programming concepts such as classes, inheritance, polymorphism, and interfaces.

### Lab 2 – EduScore
A Java application focused on exception handling and grade management.

### Lab 3 – ByteCafe
A Java application demonstrating object-oriented programming, collections, and multithreading concepts.

### Lab 4 – SecureBank
A client-server banking application using Java, networking, and a database.

### Lab 5 – TaskHub
A Java desktop task-management application using JavaFX, Spring Boot, and Maven.
